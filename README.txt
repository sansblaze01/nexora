# Nexora — site web

## Contenu
- `index.html` : accueil
- `communaute.html` : présentation du serveur et de ses activités
- `partenariats.html` : conditions et avantages des partenariats
- `style.css` : styles communs et responsive
- `assets/nexora-logo.png` : logo Nexora

## Publication sur GitHub Pages
1. Crée un dépôt GitHub public.
2. Envoie tous les fichiers et dossiers de cette archive à la racine du dépôt (pas seulement `index.html`).
3. Dans Settings > Pages, choisis `Deploy from a branch`, puis `main` et `/(root)`.
4. Enregistre et attends la publication.

Les boutons Discord pointent vers https://discord.gg/eeUZDGEQj.
